## 🔌 Protocolos de Comunicación

### CANopen (Protocolo Principal)

El R13 F implementa el protocolo **CANopen** según CiA 301 y CiA 402:

#### Objetos CANopen Principales

| Índice | Nombre | Tipo | Acceso | Descripción |
|---|---|---|---|---|
| **0x6040** | Control Word | UINT16 | RW | Palabra de control CiA 402 |
| **0x6041** | Status Word | UINT16 | RO | Palabra de estado CiA 402 |
| **0x6060** | Modes of Operation | INT8 | RW | Modo de operación |
| **0x6061** | Modes of Operation Display | INT8 | RO | Modo de operación actual |
| **0x607A** | Target Position | INT32 | RW | Posición objetivo |
| **0x6081** | Profile Velocity | UINT32 | RW | Velocidad de perfil |
| **0x606C** | Velocity Actual Value | INT32 | RO | Velocidad actual |
| **0x6064** | Position Actual Value | INT32 | RO | Posición actual |

#### PDO Mapping

**RPDO1 (Receive PDO 1)** - COB-ID: 0x200 + Node ID
- Control Word (0x6040)
- Target Velocity (opcional)

**TPDO1 (Transmit PDO 1)** - COB-ID: 0x180 + Node ID
- Status Word (0x6041)

**TPDO2 (Transmit PDO 2)** - COB-ID: 0x280 + Node ID
- Velocity Actual Value (0x606C)
- Position Actual Value (0x6064)

#### Máquina de Estados CiA 402

```
Estado               Control Word    Status Word
─────────────────────────────────────────────────
SWITCH_ON_DISABLED   -               0x0040
READY_TO_SWITCH_ON   0x0006          0x0021
SWITCHED_ON          0x0007          0x0023
OPERATION_ENABLED    0x000F          0x0027
QUICK_STOP_ACTIVE    0x0002          0x0007
FAULT                -               0x0008
FAULT_REACTION       -               0x000F
```

### Otros Protocolos (Opcionales)

- **Profibus DP**: Disponible como opción (400-900 MHz)
- **Profinet**: Disponible como opción (400-900 MHz)
- **RS232/RS485**: Socket disponible para configuración

## 🔧 Instalación

### ⚠️ Precauciones de Seguridad

**ADVERTENCIA - Riesgo de descarga eléctrica:**
- Apagar completamente la máquina antes de instalar el receptor
- Verificar la fuente de alimentación y desconectar el interruptor principal
- Desconectar el cable de interfaz entre el receptor y la caja eléctrica

### Procedimiento de Instalación

#### 1. Selección de Ubicación

**Criterios:**
- ✅ Ubicación de fácil acceso
- ✅ Visión directa entre antena del receptor y área de trabajo del transmisor
- ✅ Área despejada y libre de obstrucciones
- ✅ Protección contra vibraciones (usar amortiguadores si es necesario)

**Si no hay visión directa:**
- Usar antena externa extendida en ubicación despejada
- Solo para modelos que permiten antena externa

#### 2. Montaje Mecánico

**Instalación Recomendada:**

| Modelo | Diámetro Agujero | Tornillo Recomendado | Notas |
|---|---|---|---|
| R13 | 5 mm | DIN 7985 M5×25 | - |
| MP20 | 5 mm | DIN 7985 M5×25 | - |
| R70 | 9 mm | DIN 7985 M8×25 | También M6 con arandela |

**Accesorios Recomendados:**
- Kit de amortiguadores (para áreas de alta vibración)
- Kit magnético para montaje rápido

#### 3. Conexión Eléctrica

**Cableado Recomendado:**

| Sección | AWG | Conductores | Diámetro Exterior | Peso Aprox. |
|---|---|---|---|---|
| 1.50 mm² | 18 | 17 | 17.8 mm | 518 kg/km |
| 1.50 mm² | 18 | 25 | 21.5 mm | 730 kg/km |

**Características del cable:**
- Resistente al aceite
- Cable de control flexible
- Aprobación internacional <HAR>
- Retardante de llama (recomendado)

**Conexiones:**
1. Conectar la fuente de alimentación según diagrama de bloques
2. Verificar opción de cable neutro o tierra
3. **IMPORTANTE**: Conectar cable de tierra si está disponible
4. Seguir esquema de correspondencia entre maniobras del transmisor y salidas del receptor

#### 4. Verificación Post-Instalación

**Lista de Comprobación:**
- [ ] Receptor montado firmemente
- [ ] Cableado según especificaciones
- [ ] Tierra conectada
- [ ] Antena instalada y orientada
- [ ] Visión directa verificada
- [ ] Alimentación correcta (voltaje)
- [ ] Sin interferencias mecánicas

### Procedimientos de Diagnóstico

#### 1. Verificación de Alimentación
```bash
Síntoma: LEDs apagados
Causas:
  • Fusible quemado
  • Cable de alimentación desconectado
  • Voltaje fuera de rango

Solución:
  1. Verificar voltaje en terminales (8-36VDC o 18-240VAC)
  2. Comprobar fusible
  3. Revisar polaridad
```

#### 2. Problemas de Comunicación RF
```bash
Síntoma: Standby pasivo frecuente
Causas:
  • Obstrucciones entre antena y transmisor
  • Interferencias electromagnéticas
  • Antena dañada
  • Fuera de alcance

Solución:
  1. Verificar línea de vista
  2. Cambiar canal de frecuencia
  3. Revisar integridad de antena
  4. Reducir distancia
  5. Usar antena externa si es necesario
```

#### 3. Errores de CAN Bus
```bash
Síntoma: LED CANERR encendido
Causas:
  • Terminación incorrecta
  • Direcciones duplicadas
  • Cableado defectuoso
  • Velocidad de baudios incorrecta

Solución:
  1. Verificar jumper de terminación (120Ω en extremos)
  2. Comprobar direcciones de nodos (únicas)
  3. Revisar cableado CAN_H y CAN_L
  4. Verificar baudrate (125 kbps típico)
```

#### 4. EEPROM Corrupta
```bash
Síntoma: LED ORDER encendido
Causas:
  • EEPROM removida durante operación
  • Datos corruptos
  • EEPROM defectuosa

Solución:
  1. Apagar receptor
  2. Verificar EEPROM insertada correctamente
  3. Reprogramar con software Danfoss
  4. Si persiste, reemplazar EEPROM
```

## ⚠️ Instrucciones de Seguridad

### Regulaciones FCC

**Este equipo cumple con:**
- Parte 15 de las Reglas FCC para dispositivos Clase A
- Límites de exposición RF de la FCC
- CNR de Industry Canada para dispositivos radio exentos de licencia

**Advertencias FCC:**
⚠️ Cambios o modificaciones no aprobadas expresamente por Danfoss pueden anular la autoridad del usuario para operar este equipo.

**Operación permitida bajo dos condiciones:**
1. El dispositivo no debe causar interferencia dañina
2. Debe aceptar cualquier interferencia recibida, incluso si causa operación no deseada

### Seguridad General

#### ✅ Buenas Prácticas

- **Usar equipo ESD**: Personal de instalación debe usar equipo de protección antiestática
- **Personal calificado**: Solo personal competente y profesional debe realizar la instalación
- **Documentación**: Mantener este manual disponible para operadores y personal de mantenimiento
- **Identificación**: Identificar claramente la máquina controlada en etiqueta del transmisor
- **Mantenimiento**: Realizar servicio periódico del equipo
- **Repuestos**: Usar únicamente repuestos suministrados por Danfoss

#### ❌ Precauciones

- **NO usar** en atmósferas potencialmente explosivas (excepto modelos certificados ATEX/IATEX)
- **NO operar** cuando la visibilidad es limitada
- **NO exponer** a chorros de agua a alta presión durante limpieza
- **NO usar** si se detecta cualquier falla
- **NO dejar** al alcance de personal no autorizado
- **Retirar llave** del transmisor cuando no esté en uso

### Verificaciones Diarias Obligatorias

**Lista de Chequeo Pre-Operación:**
```
□ Verificar botón de STOP funciona correctamente
□ Comprobar características de seguridad
□ Verificar que el transmisor es el correcto para la máquina
□ Confirmar identificación clara de la máquina
□ En caso de duda: PRESIONAR STOP
```

### Procedimiento de Emergencia

**Si ocurre un incidente:**

1. **PRESIONAR STOP INMEDIATAMENTE**
2. Apagar la máquina
3. No reiniciar hasta identificar causa
4. Contactar personal de mantenimiento
5. Documentar el evento
6. Revisar procedimientos de seguridad

### Uso de Batería y Cargador

**Para transmisores con batería:**
- Usar únicamente batería original del fabricante
- Usar cargador especificado por Danfoss
- No exponer batería a temperaturas extremas
- Desechar baterías según normativas locales

### Conexión Tether (Cable Auxiliar)

**Procedimiento seguro:**
1. **SIEMPRE** presionar STOP antes de conectar cable tether
2. Conectar extremo de la máquina primero
3. Conectar extremo del transmisor después
4. Para desconectar: remover extremo del transmisor PRIMERO
5. Verificar que el cable no presente daños

**Antes de operar:**

- ✅ Confirmar que la configuración de salidas es correcta
- ✅ Validar que las funciones de seguridad funcionan
- ✅ Realizar prueba de alcance en el área de trabajo
