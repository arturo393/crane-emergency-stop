## ❓ PREGUNTAS CRÍTICAS (Antes de comprar)

Pregunta al vendedor:

1. ✅ **¿Puedo instalar mi propio software Linux?**
2. ✅ **¿Soporta SocketCAN para Python?**
3. ✅ **¿Incluye terminación 120Ω en CAN?**
4. ✅ **¿Aislamiento galvánico entre Ethernet y CAN?**
5. ✅ **¿Ejemplos de código disponibles?**
6. ✅ **¿Latencia Ethernet→CAN < 10ms?**
7. ✅ **¿Garantía y política de devolución?**
8. ✅ **¿Envío a Chile - costo y tiempo?**
