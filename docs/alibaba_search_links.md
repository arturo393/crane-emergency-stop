## 🚨 Preguntas Críticas (ANTES de Comprar)

### Para Verificar Compatibilidad con Proyecto

1. **¿Puedo instalar mi propio software Linux?**
   - Respuesta esperada: "Sí, tiene acceso root SSH"

2. **¿Soporta SocketCAN para programación en Python?**
   - Respuesta esperada: "Sí, kernel con SocketCAN habilitado"

3. **¿El puerto CAN tiene terminación 120Ω configurable?**
   - Respuesta esperada: "Sí, jumper o resistor incluido"

4. **¿Qué velocidades CAN soporta?**
   - Respuesta esperada: "125 kbps a 1 Mbps"

5. **¿Incluye aislamiento galvánico entre Ethernet y CAN?**
   - Respuesta esperada: "Sí, mínimo 1500V"

6. **¿Proporcionan ejemplos de código para CAN?**
   - Respuesta esperada: "Sí, ejemplos en C/Python disponibles"

7. **¿Tiempo de latencia típico Ethernet→CAN?**
   - Respuesta esperada: "< 10ms" (crítico para parada de emergencia)

8. **¿Garantía y política de devolución?**
   - Respuesta esperada: "12 meses garantía, 30 días devolución"
